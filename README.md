# EU banks and the rate cycle

How much did the 2022–2025 ECB rate cycle move net interest income across EU banks, and which banks lose most as rates fall?

**Status: work in progress.** There are no findings yet.

**Data cutoff:** bank-level data ends at Jun 2025, because the EBA discontinued the Transparency Exercise after the 2025 edition.

## Planned stack

Python for ingestion and checks, PostgreSQL and dbt for modeling, statsmodels for analysis, and Power BI for the dashboard.
